# Claude Documentation Directory

This directory is designated for all Claude-generated documentation files.

## Guidelines

When creating documentation, analysis reports, or markdown files related to the project:

1. **Always place documentation files in this `claude_docs/` directory**
2. Keep the project root clean - only README.md should remain in the root
3. Use descriptive filenames that indicate the content (e.g., `TRAINING_OPTIMIZATION.md`, `API_CHANGES.md`)
4. Update this index when adding new documentation
