# Instructions for Claude

## Documentation Location

**IMPORTANT**: All documentation files, reports, and markdown files created by Claude should be placed in the `/project/claude_docs/` directory.

### Guidelines:

1. **Always use `claude_docs/` for new documentation**
   - Analysis reports
   - Status updates
   - Technical documentation
   - Fix summaries
   - Configuration guides

2. **Do NOT create MD files in the project root**
   - The only exception is README.md which should remain in `/project/`
   - Keep the project root clean

3. **Naming conventions**
   - Use descriptive, uppercase filenames with underscores
   - Examples: `TRAINING_OPTIMIZATION.md`, `MODEL_DIAGNOSTICS.md`, `API_CHANGES.md`

4. **Update the index**
   - When creating new documentation, update the README.md in this directory with the new file listing

This helps maintain a clean project structure and makes it easy to find all Claude-generated documentation in one place.
